# Dharsini.ai Portfolio

A responsive, dark futuristic personal portfolio for Dharsini S., an AIML student interested in AI, Python, robotics and intelligent systems.

## Files

- `index.html` — portfolio content and structure
- `style.css` — complete visual design
- `script.js` — navigation, animations and contact form behavior
- `assets/resume.pdf` — add your real resume PDF here before publishing

## Customize before publishing

1. Replace `YOUR_EMAIL@example.com` in `script.js` with your actual email address.
2. Put your actual resume PDF at `assets/resume.pdf`.
3. Add certificate/project images or links if desired.
4. Open `index.html` in a browser to preview.

## Free hosting

This is a static website and can be hosted on services that support static HTML/CSS/JS, such as GitHub Pages.
